# 0002 不做全自动覆盖式更新

- 状态：已采纳
- 日期：2026-07-16（原记录于 `docs/logbooks/daily/2026-07-16.md`，2026-09-23 迁入决策目录）

## 背景

扩展可以检查 GitHub 上的新版本。需要明确自动更新的边界：Chrome 扩展的安装/覆盖更新涉及安全与打包约束，且可能覆盖用户本地配置。

## 决策

- 允许：检查新版本并**引导**用户下载或重新加载 unpacked 构建。
- 禁止（未经单独审批）：自动安装、自动覆盖本地设置、提示词预设、API Key 或历史数据。
- 完整的自动更新渠道（商店或自托管）需要单独的审批与设计文档。

## 影响

- 发布策略仍以手动 tag + GitHub Release 为主，见 `docs/governance/release-version-policy.md`。
- 任何触及更新/安装行为的 PR 都必须先推翻或细化本决策，并更新 `AGENTS.md` 的 Stop And Ask 清单。
