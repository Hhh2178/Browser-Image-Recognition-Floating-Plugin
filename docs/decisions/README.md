# 决策记录（Decisions）

- 编号：`NNNN-short-slug.md`，一经写下不改编号；被推翻时保留原文并更新 Status。
- 不记录：日常进展（`docs/logbooks/daily/`）、发布（`docs/logbooks/releases/`）、阶段状态（`docs/current-state.md`）。
