# Release v0.3.0

- 发布日期：2026-09-23
- 版本类型：minor——包含多项用户可见变更（默认预设固化、新增内置模板、五模板重构）
- 上一版本：[v0.2.0](v0.2.0.md)

## Highlights

1. **模型预设固化**：`DEFAULT_SETTINGS` 以已运行版本的配置为蓝本——ModelScope 魔搭居首激活（Qwen/Qwen3.8-Flash-Next、DeepSeek-V4.1-Flash、Qwen/Qwen3.8-27B，各 50 次/日上限），OpenAI 保留为停用项；所有 API Key 默认留空。
2. **新增第 6 个内置模板**「电商海报类反推」（6223 字符，源自用户自定义模板固化，提取证据存 `docs/logbooks/validations/attachments/`）。
3. **五个内置模板六段式重构**：共享脚手架 `src/features/prompts/sections.ts`（输出格式协议、置信度规则、字数下限+安全阀、JSON 骨架字段↔章节同名映射、常见缺陷清单、收尾自检）；通用图片反推 86→5005 字符、网页截图分析 89→4322、高保真 839→4186、截图视觉拆解 389→3806、美术蓝图 1004→3690。
4. **Harness 治理层建立**：`docs/requirements/`、`docs/decisions/`（0001–0003）、`docs/current-state.md`、校验门禁扩展；仓库与上游 git 历史重新关联（fast-forward，无历史改写）。
5. **范围处置**：需求 1（独立截图伴侣/屏幕外截图）经评估后放弃，见 `docs/decisions/0003-abandon-screenshot-companion.md`。
